> Módulo 05: Condicionales

Hacer que tu programa tome decisiones.

if — Si esto, entonces aquello


edad = 20

if edad >= 18:
    print("Eres mayor de edad")

Ejecución: Como edad es 20 (>= 18), se imprime el mensaje.

Estructura básica


condición:
    código que se ejecuta si es True

⚠o IMPORTANTE: La indentación (4 espacios o 1 tab) es OBLIGATORIA. Sin ella, Python da error.


# ❌ Error — sin indentación
if True
print("Hola")

# ✅ Correcto
if True:
    print("Hola")

if/else — Si esto, sino aquello


edad = 15

if edad >= 18:
    print("Puedes entrar")
else:
    print("No puedes entrar")

Salida: No puedes entrar (porque 15 < 18)

if/elif/else — Múltiples opciones


nota = 85

if nota >= 90:
    print("A — Excelente")
elif nota >= 80:
    print("B — Muy bien")
elif nota >= 70:
    print("C — Bien")
elif nota >= 60:
    print("D — Regular")
else:
    print("F — Reprobado")

Salida: B — Muy bien (porque 85 >= 80)

Python revisa las condiciones de arriba hacia abajo y ejecuta la primera que sea True.

Operadores lógicos en condicionales


edad = 25
tiene_dinero = True

if edad >= 18 and tiene_dinero:
    print("Puedes comprar alcohol")

if edad < 18 or not tiene_dinero:
    print("No puedes comprar")

Condicionales con input


respuesta = input("¿Te gusta Python? (sí/no): ")

if respuesta.lower() == "sí" or respuesta.lower() == "si":
    print("¡Genial! Sigue practicando")
else:
    print("¡Inténtalo! Python es genial")

.lower() convierte el texto a minúsculas para que "SÍ", "Si", "sí" todos funcionen.

Condicional ternario (una línea)


edad = 20
mensaje = "Mayor" if edad >= 18 else "Menor"
print(mensaje)  # Mayor

Ejemplos prácticos

Par o impar


numero = int(input("Número: "))

if numero % 2 == 0:
    print(f"{numero} es par")
else:
    print(f"{numero} es impar")

Clasificar edad


edad = int(input("Edad: "))

if edad < 0:
    print("Edad inválida")
elif edad < 13:
    print("Niño")
elif edad < 18:
    print("Adolescente")
elif edad < 65:
    print("Adulto")
else:
    print("Adulto mayor")

Calculadora con opción


num1 = float(input("Número 1: "))
num2 = float(input("Número 2: "))
op = input("Operación (+, -, *, /): ")

if op == "+":
    print(f"Resultado: {num1 + num2}")
elif op == "-":
    print(f"Resultado: {num1 - num2}")
elif op == "*":
    print(f"Resultado: {num1 * num2}")
elif op == "/":
    if num2 != 0:
        print(f"Resultado: {num1 / num2}")
    else:
        print("No se puede dividir entre cero")
else:
    print("Operación no válida")

Errores comunes

Usar = en vez de ==:


if x = 5:   # ❌ Error de sintaxis
if x == 5:  # ✅ Correcto

Olvidar los dos puntos:


if True    # ❌ Error
if True:   # ✅ Correcto

Indentación inconsistente:


if True:
print("Hola")   # ❌ Error — falta indentación

Ejercicios

  • Pide un número e imprime si es positivo, negativo o cero
  • Pide la edad y di si puede votar (18+), conducir (18+), o es menor
  • Pide un año e imprime si es bisiesto (divisible por 4, pero no por 100 salvo que sea por 400)
  • Pide una contraseña y valida que tenga al menos 8 caracteres

    • Soluciones

    
# Ejercicio 1
numero = float(input("Número: "))
if numero > 0:
    print("Positivo")
elif numero < 0:
    print("Negativo")
else:
    print("Es cero")

# Ejercicio 2
edad = int(input("Edad: "))
if edad >= 18:
    print("Puede votar y conducir")
elif edad >= 16:
    print("Puede conducir pero no votar")
else:
    print("Es menor de edad")

# Ejercicio 3
año = int(input("Año: "))
if (año % 4 == 0 and año % 100 != 0) or (año % 400 == 0):
    print(f"{año} es bisiesto")
else:
    print(f"{año} no es bisiesto")

# Ejercicio 4
password = input("Contraseña: ")
if len(password) >= 8:
    print("Contraseña válida ✅")
else:
    print(f"Muy corta — tiene {len(password)} caracteres, necesita 8")
