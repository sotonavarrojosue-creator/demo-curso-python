> Módulo 01: Hola Mundo

Tu primera línea de código en Python.

¿Qué es Python?

Python es un lenguaje de programación. Piensa en él como un conjunto de instrucciones que le das a la computadora para que haga cosas. Python es famoso porque se lee casi como inglés.

Tu primer programa

Abre tu editor de código, crea un archivo llamado hola.py y escribe:

python
Cargando Python en el navegador...

Para ejecutarlo, abre la terminal y escribe:

bash
Cargando Python en el navegador...

Salida:

python
Cargando Python en el navegador...

¿Qué pasó ahí?

  • `print()` es una **función** — le dice a Python que muestre algo en pantalla
  • Lo que está entre comillas `"¡Hola, mundo!"` es un **string** (texto)
  • Python lee el archivo línea por línea y ejecuta cada instrucción

    • Más ejemplos con print

    python
    Cargando Python en el navegador...

    Salida:

    python
    Cargando Python en el navegador...

    Python ejecuta cada print() en orden, de arriba hacia abajo.
