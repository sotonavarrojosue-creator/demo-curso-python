> Módulo 01: Hola Mundo

Tu primera línea de código en Python.

¿Qué es Python?

Python es un lenguaje de programación. Piensa en él como un conjunto de instrucciones que le das a la computadora para que haga cosas. Python es famoso porque se lee casi como inglés.

Tu primer programa

Abre tu editor de código, crea un archivo llamado hola.py y escribe:


print("¡Hola, mundo!")

Para ejecutarlo, abre la terminal y escribe:


python hola.py

Salida:


¡Hola, mundo!

¿Qué pasó ahí?

  • `print()` es una **función** — le dice a Python que muestre algo en pantalla
  • Lo que está entre comillas `"¡Hola, mundo!"` es un **string** (texto)
  • Python lee el archivo línea por línea y ejecuta cada instrucción

    • Más ejemplos con print

    
print("Mi nombre es Aaron")
print(2 + 3)
print("Tengo", 25, "años")

    Salida:

    
Mi nombre es Aaron
5
Tengo 25 años

    Python ejecuta cada print() en orden, de arriba hacia abajo.

    Comentarios

    Los comentarios son notas para ti. Python los ignora completamente:

    
# Esto es un comentario — Python no lo lee
print("Esto sí se ejecuta")

# Puedes usar comentarios para explicar qué hace tu código
# La línea de abajo suma dos números
print(10 + 20)

    Errores comunes

    Error: Forgot quotation marks

    
print(Hola)    # ❌ Error
print("Hola")  # ✅ Correcto

    Error: Wrong parentheses

    
print "Hola"   # ❌ Error (Python 2 syntax)
print("Hola")  # ✅ Correcto

    Error: Case sensitive

    
Print("Hola")  # ❌ Error — la P debe ser minúscula
print("Hola")  # ✅ Correcto
